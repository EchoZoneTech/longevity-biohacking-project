# Longevity Biohacking Project

First attempt at creating a channel for an income stream using AI generated videos.

## Project Overview

This repository contains resources for creating educational YouTube content focused on longevity and biohacking. The goal is to provide science-backed, accessible information about health optimization and lifespan extension.

## Repository Structure

### `/scripts/youtube/`
Contains video scripts and templates for YouTube content:
- **`longevity_biohacking_intro.md`** - Complete 12-minute video script covering 5 core longevity biohacks
- **`script_template.md`** - Reusable template for creating new video scripts
- **`README.md`** - Comprehensive guide on script usage and content creation

## Getting Started

1. Review the scripts in `/scripts/youtube/`
2. Customize the content to match your personal style
3. Use the template to create additional video scripts
4. Follow the production guidelines in the scripts README

## Topics Covered

The current scripts cover evidence-based longevity strategies including:
- Intermittent fasting and autophagy
- Cold exposure therapy
- NAD+ optimization
- Sleep optimization
- Exercise protocols for longevity

## Content Philosophy

All content is:
